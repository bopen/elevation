# elevation

Download, cache and clip global terrain digital elevation models: Terrain Tiles,
SRTM 30m, SRTM 90m and SRTM GL1 ellipsoidal DEMs.

If you have any feedback or you want to help out head over to our main repository:
https://github.com/bopen/elevation
